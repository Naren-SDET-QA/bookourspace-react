# Service coverage directory data

The six local JSON files are generated from the Local Government Directory (LGD) all-villages export hosted by `vanga/india-local-government-directory`. Its embedded metadata identifies the source report as `allVillagesofIndia`, the source URL as `https://lgdirectory.gov.in/downloadDirectory.do`, and export generation date as 2026-05-25. LGD is maintained by the Ministry of Panchayati Raj, Government of India.

The original open government data license is GODL-India. Required attribution: **Local Government Directory, Government of India**. The data is a local, static directory; the picker makes no network API, PIN-code, geocoding, or paid service request. Verify any disputed location against the official LGD directory.
